🤖 CODE BOT

Teach your robot to think! Snap command blocks together to guide Bit to the 🏁 flag and grab every 💎 gem. Use as few blocks as you can for 3 stars.

How to play

Tap a block at the top to add it to your program. New blocks go into the box with the green outline. Tap a 🔁 Repeat, ❓ If or ⭐ Function box to put blocks inside it.

Tap ✕ to remove a block. Tap the number on a Repeat to change it, and tap the question on an If to change what Bit checks.

▶ Run plays your whole program. ⏭ Step runs one command at a time, and the block running now glows yellow.

Keys: ↑ forward, ←/→ turn, Backspace remove last, Enter run, S step, H hint, M mute.
