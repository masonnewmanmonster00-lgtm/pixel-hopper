📊 Graph Builder

Turn data into pictures! Build bar charts and pictographs from tally charts and tables, read graphs to find the most, least, difference and total, explore line graphs and choose the right graph for the job.

How to play

🛠 Build: drag each bar up or down (or use the − / + buttons) to match the data table. In pictographs, every picture stands for more than one, so check the key.

🔎 Read: answer questions about a graph: most, least, how many more, total. 📈 Line graphs show change over time.

Get a level right with no mistakes for ★★★. A wrong answer is fine: you'll see why, so you learn something every time.

Keys: 1–6 choose, Enter check / next, M mute.
